# Aiso v1.0.2

2026-08-21

## 이번 릴리스

창 크기를 줄였을 때 버튼 글자가 버튼 밖으로 새던 문제를 고친 패치 릴리스입니다. 기능 변경은 없습니다.

## 고친 문제

- **버튼 글자가 버튼 밖으로 새던 문제** — 창을 좁히면 설정 화면의 `AI 언로드`가 `AI 언로 / 드`로, `전체 삭제`가 `전체 삭 / 제`로 두 줄이 되어 버튼 위아래로 삐져나왔습니다.

  버튼은 높이가 30px로 고정인데 줄바꿈을 막지 않았던 것이 원인입니다. 설정 화면의 각 줄은 가로로 배치되어 있어, 창이 좁아지면 버튼 칸도 함께 줄어들고 한글은 띄어쓰기가 없는 자리에서도 끊깁니다. 두 줄이 되는 순간 글자가 차지하는 높이가 41px가 되어 30px 상자를 11px 넘어갔습니다.

  이제 버튼 글자는 줄바꿈되지 않고, 버튼 칸도 좁은 창에서 함부로 줄어들지 않습니다. 버튼이 넓어진 자리에서는 글자가 가운데에 놓입니다.

  같은 증상이 나올 수 있는 곳이 설정 화면만은 아니었습니다. 이 버튼 스타일은 채팅·에이전트·캘린더·이미지·진단 센터를 포함해 화면 9곳에서 함께 쓰이므로, 이번 수정은 그 전부에 적용됩니다.

## 호환성과 주의사항

- 화면 표시만 바뀝니다. 설정, 대화, 캘린더, My DB 데이터에는 영향이 없습니다.
- v1.0.1에서 그대로 업데이트할 수 있습니다.

## 검증

- 문제가 나타나던 것과 같은 폭(656px)에서 두 버튼 모두 한 줄로 표시되고 넘침이 사라진 것을 실측했습니다.
- 버튼 스타일을 함께 쓰는 다른 화면의 배치들을 폭 300px까지 확인해, 가로로 넘치는 곳이 없음을 확인했습니다.
