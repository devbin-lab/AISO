# Aiso v1.0.1

2026-08-17

## 배포 목적

`1.0.0-a` 프리릴리스 표기가 Windows 자동 업데이트 비교에서 새 안정 배포본으로 감지되지 않을 수 있어, 정식 SemVer 안정 버전 `1.0.1`을 제공합니다.

## 변경 사항

- 앱, 작업표시줄, 설치 관리자, README에 쓰이는 Aiso 아이콘을 2베이 NAS 디자인으로 통일했습니다.
- 좌측 상태등은 점등 1개와 꺼짐 1개로 정리했습니다.
- 패키지 버전을 `1.0.1`로 올려 기존 `1.0.0` 설치본이 업데이트 후보로 판별되도록 했습니다.

## 검증

- TypeScript 타입 검사
- Windows NSIS 설치본 패키징
