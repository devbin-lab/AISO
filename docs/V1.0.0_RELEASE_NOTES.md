# Aiso v1.0.0

2026-08-17

## 정식 릴리스

v1.0.0은 Aiso의 첫 정식 릴리스입니다. 로컬·NVIDIA 모델에서의 도구 호출 안정성, 문서 기반 일정 관리, 독립형 My DB 라이브러리, ComfyUI 이미지 생성과 데스크톱 인터페이스를 하나의 제품 흐름으로 정리했습니다.

## 주요 변경

- 요청 의도에 맞춰 필요한 도구만 단계별로 노출하고, 잘못된 도구 호출과 손상된 인자를 실행 전에 차단하도록 개선
- 첨부 파일과 작업 폴더 문서를 분리해 분석하고, PDF·PPTX 등에서 근거와 함께 일정 후보를 저장하도록 개선
- 캘린더에 일간·주간·월간·목록 보기, 반복 일정, 우선순위, 기간 이동·조정과 중앙 저장소 기반 일정을 추가
- My DB를 에이전트 작업 이력과 분리된 개인 파일 라이브러리로 구성: 코어·파일 관계 그래프, 가져오기, 변경 이력, 복구, 일일 보고, 선택적 읽기 전용 Agent 조회 지원
- ComfyUI 이미지 생성의 모델 프로필·프롬프트 정규화·고품질 보정·연구 후 생성 흐름·실패 결과 처리를 개선
- 프로젝트/대화 사이드바, 설정, 캘린더, My DB의 반응형 UI와 앱 아이콘을 정비

## 호환성과 주의사항

- 기존 작업 폴더와 기존 대화는 유지됩니다. My DB는 별도의 사용자 저장소를 사용합니다.
- NVIDIA Build와 사용자 NIM은 선택 기능이며, 사용 전 모델별 스트리밍·도구 호출 지원 및 데이터 전송 범위를 확인해야 합니다.
- ComfyUI는 별도 설치가 필요하며, 모델과 워크플로의 실제 지원 범위는 사용자의 설치 환경에 따릅니다.
- 자동 권한 모드는 켜진 도구를 승인 없이 실행할 수 있으므로, 신뢰할 수 있는 모델과 작업 범위에서만 사용해야 합니다.
