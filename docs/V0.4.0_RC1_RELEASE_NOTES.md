# Aiso v0.4.0-rc.1 릴리스 노트

| 항목 | 내용 |
|---|---|
| 버전 | `0.4.0-rc.1` |
| 작성일 | 2026-08-02 |
| 기준 안정판 | `v0.3.1` |
| 상태 | Release Candidate · NVIDIA 호환 기능 사전 검증 |

v0.4.0-rc.1은 v0.3.1의 기존 기능을 기준선으로 유지하면서 NVIDIA Build API와 사용자가 운영하는 NVIDIA NIM 호환 엔드포인트를 선택적으로 연결합니다. NVIDIA는 기본 공급자가 아니며, 기존 설치는 마이그레이션 후에도 Ollama를 계속 사용합니다.

이 버전은 실제 NVIDIA 계정·Build API 키·사용자 NIM 서버를 이용한 최종 상호운용 검증 전 단계입니다. 운영 또는 중요 업무에 사용하지 마십시오.

## 주요 변경 사항

### LLM 공급자

- NVIDIA Build의 고정 주소 `https://integrate.api.nvidia.com/v1` 지원
- 사용자가 운영하는 OpenAI 호환 NIM 기본 주소 지원
- `/v1/models` 기반 모델 목록 조회와 `/v1/chat/completions` 기반 스트리밍 채팅
- 모델 이름이나 목록으로 기능을 추정하지 않고, 사용자가 요청할 때만 채팅·스트리밍·도구 호출을 검사
- NVIDIA 요청 실패 시 Ollama로 조용히 전환하지 않고 오류를 명시적으로 표시

### 자격 증명과 네트워크

- Build API 키와 선택적 NIM Bearer 키를 배포 방식·엔드포인트에 묶어 저장
- Electron `safeStorage`를 사용할 수 있을 때만 키를 암호화하고, 평문 저장 폴백 거부
- 저장된 키를 Renderer나 일반 설정 객체로 다시 반환하지 않음
- 키를 정확한 실행 대상으로만 Main 프로세스에서 로컬 사이드카 메모리에 전달
- 원격 NIM은 HTTPS만 허용하고 loopback NIM은 HTTP 또는 HTTPS 허용
- URL 사용자 정보·query·fragment, Build 주소 변경과 요청 리디렉션 거부

### 배포 재현성

- 배포용 `get-pip.py`를 PyPA 공식 `pypa/get-pip` 저장소의 변경 불가능한 commit과 SHA-256으로 고정
- 빌드 중 실제 설치된 pip 버전이 잠금값 `25.0.1`과 정확히 같은지 확인한 뒤 런타임 의존성 설치
- 최종 배포 런타임에서는 pip 패키지와 실행 파일을 제거
- 개발·패키징 도구의 전이 의존성을 현재 보안 권고가 반영된 잠금 버전으로 갱신

### 외부 데이터 전송 승인

- 일반 NVIDIA 채팅: 현재 대화 내용을 선택한 NVIDIA 대상에 전송
- 웹 조사 채팅: 대화와 수집한 공개 웹 자료 전송 전에 별도의 일회성 허가 요구
- NVIDIA Agent: 실행 전 전송 명세를 표시하고 세션 단위로 승인
  - 기본 전송: 대화, 계획 갱신, 로컬 시스템 시각
  - 선택 전송: 승인한 작업 폴더 읽기 결과, 로컬 Ollama RAG 검색 결과, 이미지 프롬프트와 생성 성공 여부·크기
  - 로컬 유지: NVIDIA·Discord 비밀값, 승인 토큰, ComfyUI 설치·모델 경로와 workflow JSON, 로컬 이미지 바이트, 사용자 스킬
- Discord NVIDIA: 데스크톱 공급자와 별도로 설정하며 Discord 대화·도구·웹 조사 결과 전송 동의와 일회성 실행 허가 요구
- Agent·웹 조사·Discord 도구는 현재 대상과 모델의 최신 `tools=supported` 검사 결과가 있어야 실행

## 설정 방법

### NVIDIA Build

1. [NVIDIA API Catalog](https://build.nvidia.com/explore/discover)에서 사용할 모델을 선택하고 NVIDIA 계정으로 Build API 키를 발급합니다.
2. Aiso의 `설정 → LLM`에서 공급자를 `NVIDIA`, 배포 방식을 `NVIDIA Build`로 선택합니다.
3. API 키를 저장합니다. 운영체제 보안 저장소를 사용할 수 없으면 Aiso가 저장을 거부합니다.
4. 설정을 저장한 뒤 `모델 목록 새로고침`을 실행하거나 정확한 모델 ID를 직접 입력합니다.
5. 일반 채팅은 채팅·스트리밍 검사 결과를 확인해 사용합니다. Agent·웹 조사·Discord에는 `기능 검사`의 최신 도구 호출 지원 결과가 추가로 필요합니다.

NVIDIA 공식 Quickstart는 Build API 요청이 NVIDIA DGX Cloud에서 호스팅되는 모델 API로 전송된다고 설명합니다. Build를 로컬 추론으로 간주하지 마십시오.

### 사용자 NIM

1. [NVIDIA NIM 요구사항](https://docs.nvidia.com/nim/large-language-models/latest/get-started/prerequisites.html)과 선택 모델의 최신 지원 표를 확인해 NIM을 별도 서버에 배포합니다. Aiso는 NIM 컨테이너를 설치하거나 관리하지 않습니다.
2. Aiso의 `설정 → LLM`에서 공급자를 `NVIDIA`, 배포 방식을 `사용자 NIM`으로 선택합니다.
3. `/v1/models`와 `/v1/chat/completions`를 제공하는 기본 주소를 입력합니다. 예: `http://127.0.0.1:8000/v1` 또는 `https://nim.example.com/v1`.
4. 서버가 Bearer 인증을 요구하면 해당 키를 저장합니다. 인증이 없는 NIM은 키 없이 사용할 수 있습니다. 그 밖의 사용자 지정 인증과 클라이언트 인증서는 현재 지원하지 않습니다.
5. 모델 목록을 새로고침하고 모델을 선택한 뒤 기능 검사를 실행합니다.

NIM의 inbound TLS 기본값은 비활성화이고 CORS 허용 origin 기본값은 `*`입니다. 외부 네트워크에 공개하기 전에 NIM 운영자가 TLS 또는 mTLS, 접근 제어, 방화벽, CORS, 로그와 인증 정책을 직접 구성해야 합니다. Aiso는 외부 NIM에 HTTPS를 요구하지만 서버 자체를 보호하거나 운영 정책을 대신 설정하지 않습니다.

## v0.3.1에서 마이그레이션

- 기존 채팅, 작업 폴더, RAG, ComfyUI, Discord와 Ollama 설정은 유지됩니다.
- 설정 스키마가 자동으로 갱신되며 활성 LLM 공급자와 Discord LLM 공급자는 기존처럼 Ollama가 기본입니다.
- NVIDIA 모델·엔드포인트·키는 자동 추정하거나 이전하지 않습니다. 사용자가 설정에서 직접 구성해야 합니다.
- NVIDIA 기능을 사용하지 않으면 v0.3.1과 동일하게 로컬 Ollama 경로를 사용할 수 있습니다.
- RC에서 v0.3.1 설치 파일로 되돌리기 전에 중요한 대화와 설정을 별도로 백업하십시오. 이전 앱이 새 설정 스키마의 모든 값을 이해한다고 보장하지 않습니다.

## 이용 권한과 데이터 처리 경계

Aiso의 Apache-2.0 라이선스는 NVIDIA API, NIM 컨테이너, 선택한 모델 또는 생성물에 관한 사용 권한을 부여하지 않습니다. 각 사용자는 현재 NVIDIA 계약과 모델별 제3자 라이선스를 직접 확인해야 합니다. 아래 내용은 2026-08-02에 확인한 공식 자료의 요약이며 법률 자문이 아닙니다.

- NVIDIA Developer Program의 hosted endpoint는 프로토타이핑 용도이고, self-hosted NIM은 최대 16개 GPU에서 연구·애플리케이션 개발·실험 용도로 제공됩니다. NVIDIA FAQ는 실제 최종 사용자 제공이나 업무 거래를 포함한 production 사용에는 NVIDIA AI Enterprise 라이선스가 필요하다고 설명합니다.
- NVIDIA API Trial Terms는 API와 생성물의 production 사용을 금지하며, 제공된 크레딧을 모두 사용한 뒤 또는 production에 사용하려면 NVIDIA나 제3자 서비스 제공자의 별도 구독이 필요하다고 규정합니다. 무료·무제한 서비스로 전제하지 마십시오.
- Trial Terms는 API Catalog에 기밀 정보, 통제·민감 데이터와 별도 허용되지 않은 개인정보를 보내지 않도록 규정합니다. 또한 세션 지표·오류/실행 로그와 User Content·Generated Content가 서비스 및 AI 모델 개선, 보안·부정 사용 감시에 이용될 수 있다고 명시합니다. 따라서 Build에 비밀값이나 민감한 작업 자료를 보내지 마십시오.
- 생성물의 권리는 선택한 API·모델·제3자 라이선스에 따라 달라질 수 있으며, 모델과 생성물의 정확성·권리·적합성은 Aiso와 NVIDIA가 보증하지 않습니다.
- 사용자 NIM의 데이터 위치·보존·로그·접근 권한은 배포 운영자가 정합니다. 자체 호스팅이라는 이유만으로 안전하다고 가정하지 말고 실제 구성을 검토하십시오.

## 알려진 제약사항

- 실제 NVIDIA Build와 사용자 NIM에 대한 최종 실계정·실서버 QA는 이 RC 작성 시점에 수행하지 않았습니다.
- 모델 목록, 모델 ID, 사용 한도, 비용, 이용 약관과 모델별 기능은 외부 서비스 상태에 따라 바뀔 수 있습니다.
- 기능 검사는 작은 실제 API 요청을 사용하며 비용 또는 크레딧을 소비할 수 있습니다. 검사 결과는 해당 대상·모델에 묶이고 설정 변경 또는 만료 후 다시 확인해야 합니다.
- Aiso가 사용하는 호환 범위는 모델 조회와 채팅 스트리밍 중심입니다. NIM의 전체 관리·추론 API 지원을 의미하지 않습니다.
- 일부 모델은 채팅은 가능하지만 도구 호출 형식이 호환되지 않을 수 있습니다. 이 경우 일반 채팅만 사용하십시오.
- NVIDIA 경로는 기존 Ollama 임베딩 모델을 대체하지 않습니다. NVIDIA Agent에서 RAG를 승인한 경우에도 loopback Ollama가 필요합니다.
- NVIDIA 연동 실패 시 자동으로 Ollama에 재전송하지 않습니다. 사용자가 설정에서 공급자를 직접 변경해야 합니다.
